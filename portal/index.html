시험 시작 절차 (실제 EX294 흐름)

현재 화면은 외부 터미널(foundation) 입니다. 실제 시험처럼 여기서 control 노드로 접속해 작업합니다.

1. control 노드로 접속

ssh greg@control        # 무암호(키 사전배포). hostname -f → control.lab.example.com

2. 작업 디렉토리 / 설정 (문제 1)

sudo dnf install -y ansible-core     # 또는 ansible
mkdir -p ~/ansible && cd ~/ansible

inventory 그룹(dev/test/prod/balancers/webservers)과 ansible.cfg(collections_path, roles_path, remote_user, become)를 문제 1 요구대로 직접 작성하세요.

3. 노드 연결 확인

ansible all -m ping          # 5개 노드 SUCCESS (키 이미 배포됨)
ansible all -m command -a 'id'   # become=root 확인

4. 문제 풀이

왼쪽 문제 패널의 각 과제 요구사항을 보며, control 노드 터미널에서 플레이북을 작성·실행하세요. 자료는 http://redhat.example.com/materials|material|download/ 에서 받습니다.

5. 채점

rhce-grade        # control 노드에서 실행 → 실제 시스템 상태로 자동 채점

정답 텍스트를 맞췄는지가 아니라, 플레이북 실행 결과(실제 상태)를 검사합니다.

🔎 채점 (outcome-based)

이 랩은 여러분이 입력한 명령/플레이북을 실제로 실행하고, 그 결과로 바뀐 시스템 상태를 검사합니다. (repo 설정 여부, 패키지 설치 여부, 파일·유저·크론 생성 여부 등)

control 노드 터미널에서:

rhce-grade

각 문제에 대해 [PASS]/[FAIL]/[SKIP] 과 합계를 출력합니다. SKIP은 컨테이너 커널 제약(SELinux enforcing, 실디스크 LVM 등)으로 실검증이 불가한 항목입니다.

개별 문제만 채점

rhce-grade 1      # 문제 1만
rhce-grade 8 17   # 문제 8, 17만

🔄 초기화 (다시 풀기)

rhce-reset 17     # 특정 문제만 처음 상태로
rhce-reset 7 8    # 여러 문제 한번에
rhce-reset-all    # 전체 초기화(새 시험 시작)

rhce-reset <번호> 는 해당 문제의 산출물(플레이북·노드 상태)만 되돌립니다. rhce-reset-all 은 작업 디렉토리 전체(플레이북·인벤토리·스왑파일 등)를 비우고 모든 노드를 처음 상태로 되돌려 새 시험을 시작합니다. (-y 로 확인 생략)
